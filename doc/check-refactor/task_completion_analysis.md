## 二、严重缺陷清单

### 🔴 P0级 - 严重缺陷（需立即修复）

#### 1. **前视偏差（Lookahead Bias）**
- **位置**：[hikyuu_integration.py:171](hikyuu_integration.py#L171)
- **问题**：训练标签使用未来数据 `shift(-self.label_shift)`
- **影响**：模型性能虚高，实盘无法复现
```python
# 缺陷代码
label = df["close"].shift(-self.label_shift) / df["close"] - 1
df["label"] = label  # 训练和预测使用相同逻辑
```

#### 2. **回测功能缺失**
- **位置**：[run_backtest.py](scripts/run_backtest.py)
- **问题**：只实现了信号统计，未调用 Hikyuu Portfolio/TradeManager
- **影响**：无法评估策略真实表现
```python
# 当前只是统计
summary = {
    "total_signals": len(rows),
    "unique_dates": len(dates),
    # 缺少：收益率、夏普比率、最大回撤等
}
```

#### 3. **环境变量污染**
- **位置**：[hikyuu_integration.py:57-73](hikyuu_integration.py#L57)
- **问题**：模块导入时修改全局 HOME 环境变量
- **影响**：可能影响其他模块，多进程环境下数据污染

---

### 🟡 P1级 - 中等缺陷

#### 4. **错误处理不当**
- **位置**：多个脚本
- **问题**：关键错误被降级为警告，继续执行
- **影响**：数据异常被忽略，难以发现问题

#### 5. **数据处理不一致**
- **位置**：[train_model.py:78-81](scripts/train_model.py#L78)
- **问题**：训练和预测使用不同的预处理流程
- **影响**：模型预测准确性下降

---

### 🟢 P2级 - 轻微缺陷

#### 6. **性能优化缺失**
- 无批处理优化
- 重复计算无缓存
- 大数据集处理效率低

#### 7. **测试覆盖不足**
- 缺少前视偏差测试
- 无集成测试
- 缺少边界条件测试
