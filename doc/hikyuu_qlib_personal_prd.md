# Hikyuu × Qlib 个人量化工作站 PRD

## 1. 项目背景

- 个人量化投资者常使用 **Hikyuu** 获取行情、计算技术指标与进行策略回测，但缺乏机器学习建模与实验管理能力。
- **Qlib** 提供了完整的因子工程、模型训练、AutoML 与回测分析，但需要稳定的数据源与策略执行生态。
- 目标是构建一套适用于个人投资者的“桌面级量化工作站”，一站式完成 **数据获取 → 特征加工 → AI 建模 → 策略执行 → 实盘反馈**。

## 2. 目标用户

| 用户类型 | 特征 | 核心诉求 |
| --- | --- | --- |
| 量化爱好者 | 熟悉 Python 与基础指标 | 想体验机器学习择时/选股，降低数据准备与建模门槛 |
| 技术指标型交易者 | 习惯在 Hikyuu 做指标、回测 | 期望自动化处理更多特征，测试策略效率更高 |
| 兼职自营投资者 | 有稳定策略，执行半自动 | 希望快速试验新想法、采信 AI 信号但仍保持人工把控 |

> **硬件平台要求（当前阶段）**  
> - 支持操作系统：macOS（Apple Silicon，M1/M2 系列）  
> - 建议配置：16GB 内存以上、推荐 512GB SSD（用于存放行情与实验数据）  
> - 其他平台支持计划：待 MVP 验证后评估 Windows/ Linux 适配优先级

## 3. 产品目标

1. 数据一键接入：Hikyuu 行情数据可直接加载到 Qlib。
2. 快速建模：提供预置特征模板与训练脚本，最少配置完成 AI 模型训练。
3. 策略执行闭环：Qlib 信号自动转换为 Hikyuu 组合信号，支持回测与半自动调仓。
4. 便捷监控与复盘：训练、信号、回测结果自动记录，便于复盘与迭代。

## 4. 功能需求

### 4.1 数据与特征
- **数据接入向导（P0）**  
  - 脚本/简易 UI 指引用户配置 Hikyuu 数据目录、市场、标的、时间范围。  
  - 默认支持日线 HDF5 数据，提供分钟级扩展选项。
- **Qlib DataLoader 适配（P0）**  
  - 提供 `HikyuuDataLoader`，默认按标的列表加载开高低收量额、复权因子（adjfactor）等核心字段。  
  - 支持异常数据检测、缺口提示与日志输出，提供可选的分片/增量加载模式以控制内存占用。  
  - 在文档中给出推荐的数据规模与性能建议。
- **特征模板（P1）**  
  - 附带常用技术指标组合（EMA、MACD、RSI、量价等），导出为 Qlib 特征。  
  - 支持 YAML/JSON 模板，自定义指标参数。

### 4.2 建模与实验
- **快速训练脚本（P0）**  
  - 默认 LGBModel + 基础指标数据集，一键训练并生成预测。  
  - 支持命令行参数指定训练窗口、评估切分、模型输出目录。
- **实验记录（P1）**  
  - 默认使用 Qlib 的 `R` 模块在本地记录参数、指标与预测文件，确保轻量可用。  
  - 提供可选的 MLflow 接入指南（建议列入 P2），便于后续扩展到网络或团队协作环境。  
  - 提供简化查看方式（命令行或轻量网页）。
- **约束机制（P1）**  
  - 预设训练资源上限、评估指标阈值（如信息比率、最大回撤）。  
  - 记录数据版本与特征编排，确保训练可复现。

### 4.3 策略执行
- **信号转换适配器（P0）**  
  - 将 Qlib `pred.pkl`（MultiIndex DataFrame：datetime、instrument、score）转换为统一的 Hikyuu 信号格式（CSV/JSON：datetime, instrument, action, weight/score）。  
  - 支持 Top-K 选股与择时信号两类核心场景的映射规则。  
  - 支持调仓周期、阈值、目标持仓上限等参数，并输出接口文档。
- **回测脚本（P0）**  
  - 调用 Hikyuu Portfolio/TradeManager 完成回测，输出收益曲线与指标。  
  - 可选导出 CSV 或图形结果。
- **半自动执行（P1）**  
  - 在 Hikyuu GUI/命令行中展示格式化调仓建议（表格/HTML 报告），用户确认后再执行。  
  - 设定仓位限制、止损止盈等安全约束。
- **实盘选项（P2）**  
  - 若用户具备实盘接口，可配置信号自动下单，设置 Fail-safe（无信号或波动异常时停用）。

### 4.4 监控与复盘
- **日志与监控（P1）**  
  - 记录数据更新、训练、信号生成、执行结果，提供简易日志管理。  
  - 监控关键指标（收益、波动、胜率），支持阈值告警（邮件/桌面提醒）。
- **复盘工具（P2）**  
  - 自动生成策略周/月度报告：收益、回撤、持仓结构、指标分布等。  
  - 支持对比多个实验结果与回测表现。

### 4.5 配置与示例资产
- **配置优先（P0）**  
  - 所有可变参数（标的池、时间区间、特征列表、模型参数等）统一抽离至 `config.yaml`/`config.json`。  
  - 脚本默认读取配置文件，用户 80% 场景仅需修改配置即可完成迭代。
- **端到端示例策略（P0）**  
  - 提供一套完整的示例（如 Alpha158 + LightGBM 的中证 500 选股策略），包含数据准备、训练、信号转换、回测与报告。  
  - 示例兼作集成测试与用户学习范本。

## 5. 用户旅程

1. **安装配置**  
   - 通过一键脚本安装 Hikyuu（含数据）与 Qlib 环境，并运行 `check_env.py` 验证依赖、数据路径、环境变量。  
   - 配置环境变量：`QLIB_DATA_SOURCE=hikyuu`、`QLIB_HIKYUU_INSTRUMENTS=...`。
2. **数据准备**  
   - 运行 `prepare_data.py`，加载 Hikyuu 行情，生成 Qlib Dataset。  
   - 可选设置特征模板。
3. **模型训练**  
   - 调用 `train_model.py`，使用默认参数训练模型并输出预测。  
   - 自动记录训练指标与日志。
4. **策略执行**  
   - 运行 `export_signals.py` 生成 Hikyuu 信号。  
   - 在 `run_backtest.py` 或 Hikyuu GUI 中加载信号，完成回测/调仓建议。  
   - 可选开启半自动或实盘接口。
5. **复盘迭代**  
   - 查看日志与报告，调整指标或训练参数，重复流程。
   - 可选运行 `run_all.py` 或主控脚本，按需串联各步骤执行。

## 6. 约束与安全

- **数据合规**：确保数据来源合法；明示用户应遵循当地监管政策与券商协议。  
- **资源限制**：默认限制训练耗时与内存；引导用户使用增量加载。  
- **风险控制**：信号标记为“建议”，需人工确认或设定多重阈值；提供仓位、止损、资金管理模板。  
- **透明性**：输出特征重要度、预测区间、预测分布图等可解释信息；保留模型版本与参数。  
- **恢复方案**：模型异常时提示回退至传统策略或手动模式；记录问题与 FAQ，方便排查。

## 7. 交付计划（建议）

| 阶段 | 时间 | 关键产出 |
| --- | --- | --- |
| MVP | 2~3 周 | 数据适配脚本、快速训练脚本、回测脚本、基础文档（README、CONFIG_GUIDE、FAQ）、示例策略 |
| Beta | 4~5 周 | 指标模板、信号转换、实验日志、半自动调仓支持 |
| GA | 6~8 周 | 监控告警、复盘报告、示例策略、跨平台兼容验证 |

## 8. 验收标准

- 默认配置下，用户可在 1 小时内完成数据准备、训练与回测整个流程。  
- 所有脚本提供示例配置并能跑通；错误提示友好且可追踪。  
- 模型训练、信号输出、Hikyuu 回测结果均有日志/报告留存。  
- 关键约束（资源、风控、合规提示）落实到脚本或说明文档。  
- 提供至少一套示例策略，包含指标、预测、回测与复盘示范。

## 9. 风险与应对

- **环境复杂性**：提供 Conda/Docker、一键脚本与详细文档；常见错误写入 FAQ。  
- **数据质量差异**：脚本内置数据完整性检查与缺失提示。  
- **模型误用风险**：强调信号为建议需二次确认，提供默认风控阈值。  
- **用户支持压力**：引导用户加入社区渠道，整理知识库和问题登记表。

---

本 PRD 面向个人独立投资者，以低门槛、高可用为核心，确保在有限资源与安全前提下，让 Hikyuu 与 Qlib 的优势互补，帮助用户快速构建自己的量化 AI 研发与执行闭环。

## 10. 后续拓展方向（参考）

- **轻量级 UI**：在输出阶段生成结构化 JSON/CSV 及基础图表，为未来接入 Streamlit/Gradio 等可视化工具打好数据接口。  
- **MLflow/云化升级**：当个人需求扩大或小团队协作时，可升级为 MLflow + 远程存储方案，实现多端访问。  
- **实盘接口扩展**：在安全验证充分后，可逐步接入券商/模拟交易 API，完成策略实盘自动化。  
- **社区模板生态**：鼓励用户沉淀指标模板、策略脚本与配置，形成可分享的资产库，促进学习与复现。
